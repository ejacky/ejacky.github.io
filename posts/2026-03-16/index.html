使用 Chrome DevTools MCP 远程调试

描述信息
March 16, 2026 · 作者

1. 启用 Chrome 远程调试#

参考：Chrome DevTools MCP 官方文档

  1. 打开 chrome://inspect/#remote-debugging
  2. 确保 Chrome 版本 ≥ 144 并启用远程调试

2. 在 Cursor 中配置 MCP#

{
  "mcpServers": {
    "chrome-devtools": {
      "command": "npx",
      "args": ["chrome-devtools-mcp@latest", "--autoConnect", "--channel=beta"]
    }
  }
}
